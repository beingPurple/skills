# 09 — Player knowledge / intel system

Type: grilling
Status: open
Blocked by: 01, 03

## Question

The pitch rests on decisions made from "what the player knows about the country and the world." Define:

- **What the player actually knows**, and how it is surfaced without becoming reading they have no time for (a codex? learned facts? fog that clears?).
- How **knowing more changes what a headline means** — spotting a lie, seeing a faction's fingerprints, valuing a scoop.
- How knowledge is **acquired** over a playthrough.
